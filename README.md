# SelfBet

让自己上瘾的学习系统：任务 → 积分秒到账 → 开宝箱 → 商城兑现实奖励。

## 技术栈

- 后端：Go + Gin + GORM + **MySQL 8.x**（兼容 SQLite 双驱动，`config.json` 一键切换）
- 前端：Vue 3 + Vite + Vant 4 + PWA（构建产物 embed 进后端二进制）
- 部署形态：**1 个二进制 + 1 个 MySQL 库**（本地与服务器可共享同一数据库）

## 快速开始

1. 准备一个 MySQL 库（本地或远程均可）
2. 编辑 `backend/config.json`：

```json
{
  "port": 8080,
  "db_driver": "mysql",
  "db_dsn": "用户:密码@tcp(主机:3306)/selfbet?charset=utf8mb4&parseTime=true&loc=Local"
}
```

3. 双击 `backend\server.exe`（首次启动自动建表，登录密码默认 `kaytodo`，存于数据库 `settings` 表——改密码直接改表或后续做改密接口）
4. 浏览器打开 `http://localhost:8080`

> 登录密码**不在配置文件里**——它在数据库 `settings` 表中，`config.json` 只存数据库连接信息。

### 手机访问（同一 WiFi）

1. 查电脑内网 IP（`ipconfig` 里的 IPv4 地址，如 `192.168.1.5`）
2. 手机浏览器打开 `http://192.168.1.5:8080`
3. iOS：Safari → 分享 → 添加到主屏幕；安卓：Chrome → 菜单 → 添加到主屏幕

## 一键重新构建

改完代码后双击根目录 `build.bat`：

```
[1/4] npm run build           # 构建前端
[2/4] 拷贝 dist → backend/web/dist
[3/4] go build                # Windows 自包含 server.exe
[4/4] GOOS=linux go build     # Linux amd64 版（服务器部署用）
```

开发期热更新：`backend` 目录跑 `server.exe`，`frontend` 目录跑 `npm run dev`，访问 vite 的 5173 端口（已配代理）。

## 数据与备份

- 数据库：MySQL（连接信息在 `backend/config.json`，该文件已被 gitignore，永不进仓库）
- 备份：`mysqldump selfbet > backup.sql`，建议每日一次
- 查看数据：DBeaver / Navicat / DataGrip 等任意 MySQL 客户端
- 数据库迁移工具：`backend/migrate.exe`（SQLite→MySQL、MySQL→MySQL 全量复制 + 逐表校验）

## 功能

- **单密码门锁**：无用户系统，密码存于数据库 `settings` 表（默认 `kaytodo`）
- **任务**：一次性 / 每天 / 每周重复；分组（可管理+筛选）；**列表按分组排序**（未分组最上→分组按管理顺序→组内手动序），拖拽仅限组内；**新任务自动置顶到所属分区**；每日任务自动挂在"进行中"；**一次性任务到截止日当天自动开始**（逾期后保持，补完成照发奖励）；**多轮领取**（可开关：完成不消失，每轮按积分入账，宝箱每轮生效）；截止日期 + 未完成罚分（**逾期后补完成照发奖励、罚分不退、任务不删**；连续多天没打开只补罚最近一天，按流水判定、幂等防重）
- **刷力扣双任务示范**：「刷力扣5题」25 分/天带 -25 罚分 + 「加刷一道力扣」5 分/轮无惩罚——超额题即做即领
- **自定义宝箱 + 道具掉落**：自建宝箱类型（名称 + 积分范围 + 冷却）；**道具掉落动态配置**——每个宝箱自选掉落道具（7 种）、各自概率与数量，剩余概率自动归积分；宝箱完成掉落进**背包**手动开启（不再自动开）
- **道具系统（7 种）+ 图鉴**：积分利息卡 / 余额利息卡 / 冷却重置卡 / 免罚金牌 / 幸运符 / 双倍卡 / 运势卡；触发型道具走 pending_effects 队列；背包页右上角 **？** 进道具图鉴看全部效果
- **商城**：自定义商品 + 数量兑换 + 冷却限购 + 购买记录（可按商品筛选，卡片式样式）；**透支兑换**——积分可透支至 -500 与罚分共用同一底线，按钮三态（兑换/透支兑换/超额度禁用）；商品 ☰ 拖拽排序
- **余额（现金钱包）**：10 积分 = 1 元兑换，现实中花钱后手动记消费账；**积分底线 -500**（罚分与商城透支共用，永不击穿）
- **农场**：4×6=24 块田（初始 1 块，50 分起每块 +40 顺序开垦）；种植免费，每轮固定收 200 农场积分×产量系数（无随机），**每田每天限收 2 轮**（超轮次熟了挂着过夜、永不枯死）；农场积分 100:1 整数提现回主积分（小数留存）；升级三线各 10 级（产量 A 收获+2% / 产量 B 收获+6% 但周期+8% / 周期 C 缩短）互相制衡；一键全种/一键全收
- **日程表**：新页面（「我的」→ 日程）——**周/日视图**，任务填写「计划开始/结束时间」后按分钟精确定位成色块（浅分组色），每日任务每天渲染、每周任务按周几渲染；已完成任务隐藏；纯展示不影响任何结算
- **统计页**：今天/昨天/本周/本月获得 + GitHub 式热力图（**分位数自适应色阶**：正数日绿色四档、负数日红色三档——最高日必深绿、最大亏损日必深红；26 周/一年切换，月份轴+悬停气泡）+ 全量流水（日期范围筛选）+ **净值口径统一**（收益-惩罚）；**今日明细可撤回**（仅当天、仅任务完成类，删行式——余额/轮数/统计/热力图自动重算；宝箱/罚分/商城/道具/农场记录不可撤）
- **账本**：所有积分进出的流水（绿收红支）+ 累计统计
- **跨天机制**：全 App 零定时器——daily/weekly 状态按当前时间实时计算，罚分惰性结算（打开任务页/统计页即触发），冷却与统计读时现算
