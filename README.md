# SelfBet

让自己上瘾的学习系统：任务 → 积分秒到账 → 开宝箱 → 商城兑现实奖励。

## 技术栈

- 后端：Go + Gin + GORM + SQLite（modernc 纯 Go 驱动，免 CGO）
- 前端：Vue 3 + Vite + Vant 4 + PWA（构建产物 embed 进后端二进制）
- 部署形态：**1 个 `server.exe` + 1 个 `data/` 文件夹**

## 快速开始

1. 双击 `backend\server.exe`（或在该目录命令行运行）
2. 浏览器打开 `http://localhost:8080`
3. 访问密码配置在 `backend/data/config.json` 的 `password` 字段（修改后重启生效）

### 手机访问（同一 WiFi）

1. 查电脑内网 IP（`ipconfig` 里的 IPv4 地址，如 `192.168.1.5`）
2. 手机浏览器打开 `http://192.168.1.5:8080`
3. iOS：Safari → 分享 → 添加到主屏幕；安卓：Chrome → 菜单 → 添加到主屏幕

## 一键重新构建

改完代码后双击根目录 `build.bat`：

```
[1/3] npm run build      # 构建前端
[2/3] 拷贝 dist → backend/web/dist
[3/3] go build           # 打出含前端的自包含 server.exe
```

开发期热更新：`backend` 目录跑 `server.exe`，`frontend` 目录跑 `npm run dev`，访问 vite 的 5173 端口（已配代理）。

## 数据与备份

- 数据库：`data/selfbet.db`（启动目录下的 data 文件夹）
- 备份 = 复制该文件；建议每日复制一份到 `data/backups/`
- 查看数据：DB Browser for SQLite 双击打开

## 功能

- **单密码门锁**：无用户系统，密码在 `data/config.json`
- **任务**：一次性 / 每天 / 每周重复；分组（可管理+筛选）；**列表按分组排序**（未分组最上→分组按管理顺序→组内手动序），拖拽仅限组内；每日任务自动挂在"进行中"一键完成；**多轮领取**（可开关：完成不消失，每轮按积分入账，宝箱每轮生效）；截止日期 + 未完成罚分（一次性任务逾期扣分、每日任务当天没完成扣分；**逾期后补完成照发奖励、罚分不退、任务不删**；连续多天没打开只补罚最近一天）
- **刷力扣双任务示范**：「刷力扣5题」25 分/天带 -25 罚分 + 「加刷一道力扣」5 分/轮无惩罚——超额题即做即领
- **自定义宝箱**：自建宝箱类型（名称 + 积分范围），任务关联宝箱并设掉率，完成时概率开出随机积分（含到账音效动效）
- **商城**：自定义商品 + 数量兑换 + 冷却限购（如"奖励自己一次"350 分 7 天冷却）+ 购买记录（可按商品筛选）；商品 ☰ 拖拽排序
- **余额（现金钱包）**：10 积分 = 1 元兑换，现实中花钱后手动记消费账
- **农场**：4×6=24 块田（初始 1 块，50 分起每块 +40 顺序开垦）；种植免费，每轮固定收 200 农场积分×产量系数（无随机），**每田每天限收 2 轮**（超轮次熟了挂着过夜、永不枯死）；农场积分 100:1 整数提现回主积分（小数留存）；升级三线各 10 级（产量 A 收获+2% / 产量 B 收获+6% 但周期+8% / 周期 C 缩短）互相制衡；一键全种/一键全收
- **统计页**：今天/昨天/本周/本月获得 + GitHub 式热力图（26 周/一年切换，月份轴+悬停气泡）+ 全量流水（日期范围筛选）；**今日明细可撤回**（仅当天、仅任务完成类，删行式——余额/轮数/统计/热力图自动重算；宝箱/罚分/商城/农场记录不可撤）
- **账本**：所有积分进出的流水（绿收红支）+ 累计统计
- **跨天机制**：全 App 零定时器——daily/weekly 状态按当前时间实时计算，罚分惰性结算（打开任务页/统计页即触发），冷却与统计读时现算
