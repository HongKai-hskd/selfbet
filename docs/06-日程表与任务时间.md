# 任务时间与日程表（需求定稿）

> 状态：📋 **需求已定稿，待开工**。7 个待拍板问题已全部由用户确认（2026-09-29）。
> 机制边界（重要）：**日程时段是纯展示，零结算语义**——不填时间不罚、时段过了没完成也不罚，罚分仍然只看「周期内有没有完成行」（docs 结算规则不变）。

## 一、时间字段：类型自适应表单（用户拍板）

三种任务类型看到不同的时间字段：

| 任务类型 | 表单字段 | 存储 |
| --- | --- | --- |
| 一次性（once） | 预期开始时间 / 预期结束时间（日期+时间，两步选择器） | `expected_start_at` / `expected_end_at`（datetime，可空） |
| 每日（daily） | 计划开始 / 计划结束（**只能填时间**，无日期=每天重复） | `expected_start_time` / `expected_end_time`（'HH:MM' 文本，可空） |
| 每周（weekly） | 周几（单选）+ 计划开始 / 结束时间 | 上述两个时间字段 + `expected_weekday`（1~7，可空） |

- 校验：结束 > 开始（同天内）；切换任务类型时清空不适用的时间字段
- **与截止日期独立**（用户拍板）：截止=罚分线，预期时间=计划时段，互不覆盖
- 日程表**只显示时间字段齐全的任务**；**已完成的直接隐藏**（用户拍板）

## 二、日程表页面

| 项 | 定稿 |
| --- | --- |
| 入口/路由 | 「我的」页入口卡 → `/schedule` 子页面（nav-bar 返回），与背包同款 |
| 视图 | **周视图（默认）+ 日视图**；月视图二期 |
| 翻页 | ← → 前后周/日 + 「今天」快捷键 + 范围标题（如 2026年9月27日 - 10月3日） |
| 时间轴 | 0~24 点整点刻度、可滚动；**无 now 红线**（用户拍板不要） |
| 块定位 | 按分钟换算 top/height，跨小时块跨行渲染 |
| 块颜色 | **浅 tag 色**：分组色 12% 透明底 + 同色文字 + 左侧 3px 同色竖条；无分组=默认蓝 |
| 块内容 | 任务名（截断）+ 起止时间；**纯展示，无点击交互**（用户拍板） |
| 完成任务 | **直接隐藏**（用户拍板） |
| 数据过滤 | 只显示时间字段齐全且未完成的任务；每日任务在周视图的每一天都渲染时段；每周任务只在对应周几渲染 |
| 跨天 | **不允许**：结束必须与开始同一天（用户拍板） |
| 重叠处理 | 同时段多任务：同列内并排分栏（平分宽度），实现细节开发者定 |

## 三、实现细节决定（开发者定，用户已授权"直接优化好"）

1. 每日任务的时段在日历上 = 该任务在可见范围内**每一天**都渲染一个块
2. 每周任务 = 周几匹配的那天渲染
3. 一次性任务 = 按日期落在对应列
4. 表单切换任务类型时，清空不适用的时间字段（once↔daily/weekly 字段形状不同）
5. 时段渲染与罚分结算**完全解耦**——改时间不影响任何积分逻辑

## 四、实施顺序

3. 日程页骨架（周/日切换、翻页、时间轴滚动）
