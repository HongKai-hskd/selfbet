# 背包与道具系统（需求草案）

> 状态：📋 **需求对齐中，未开工**。所有「待拍板」问题由用户逐条确认后才进入开发。
> 机制对照 docs/01：本系统的乐趣核心 = 攒箱子的期待感（变率奖励） + 自选开箱时机的仪式感。
> 关联优化：「我的」页余额记录展示改造（见第三节）。

## 一、背包系统（宝箱改造）

### 现状 vs 目标

| 环节 | 现状 | 目标 |
| --- | --- | --- |
| 掉落 | 完成任务 → 按掉率判定 → **立即自动开箱**积分入账 | 完成任务 → 按掉率判定 → 宝箱**进背包**（未开启状态） |
| 入账 | 开箱即入账 | **用户开箱时才入账**（积分流水记在开箱时刻） |
| 查看 | 无箱体概念，只看得到流水 | 背包页列出所有未开宝箱（按类型聚合 + 数量） |
| 开箱 | 自动 | 用户自选时机手动开（单个开 / 全部开启） |
| 统计口径 | 开箱日=入账日 | **不变**：开箱时才写流水，热力图/统计自洽 |

### 核心规则（草案）

1. 任务完成时按掉率判定，命中 → 「🎁 获得 宝箱名 ×1」，不再产生即时积分
2. 掉落**不写积分流水**（未入账）；开箱时写 box 流水（金额=min~max 随机，规则不变）
3. 背包按宝箱类型聚合显示（签到宝箱 ×3 / xx宝箱 ×1 …），每类可**单开**或**全部开启**
4. 开箱动效复用现有金色庆祝屏；「全部开启」逐个弹出或汇总展示（拍板 #3）
5. 背包入口：「我的」页新增「背包」入口卡片 → 跳转独立子页面（带返回导航），**不动底部 4 Tab 结构**
6. 任务完成动效调整：有掉落 → 「🎁 获得 宝箱 ×1」；无掉落 → 维持「+N 积分到账」
7. 到账弹窗/明细撤回口径随之调整：撤「任务完成行」只退任务积分；宝箱进了背包还没入账，无流水可撤（待拍板 #6）

### 待拍板问题

| # | 问题 | 选项 | 我的倾向 |
| --- | --- | --- | --- |
| 1 | 宝箱延迟开启 = 奖励延迟，与 docs/01「即时」铁律冲突，怎么权衡 | A 接受：攒箱期待感本身就是另一种多巴胺（开箱变成小赌注）B 折中：掉落时先给保底积分入账，开箱另给加成 | A——攒箱的期待感成立，但如果你想要"完成任务必有所得"就选 B |
| 2 | 背包里的宝箱有无过期机制 | A 无期限，永久存放 B N 天不开自动开启/作废 | A（简单，避免焦虑感） |
| 3 | 要不要「全部开启」 | 要 / 不要 | 要，攒多了一个个点很烦 |
| 4 | 开箱积分区间 | 维持各宝箱类型现有 min~max 配置 | 维持不变 |
| 5 | 未开宝箱总数要不要在别处提醒（我的页角标 / 任务页红点） | 要 / 不要 | 要，"有箱子没开"是回来的钩子 |
| 6 | 撤回口径微调 | 任务行撤回时，若该次掉落的宝箱已进背包，背包里的箱子要不要一并收回 | 要收回（撤回=整次完成作废） |

## 二、道具系统（二期占位，待定义）

> 目前只有"背包和道具"这个说法，道具本身没有定义。需要用户补充设想：

1. 道具从哪来：商城购买 / 任务掉落 / 宝箱开出？
2. 道具有什么效果：全局 buff（如下次任务双倍）、单次使用（重掷宝箱/补签卡）、任务加成？
3. 道具有没有有效期、堆叠上限？
4. 第一版是否只做「宝箱背包」，道具留二期？（我的建议：是，先把宝箱闭环跑顺）

## 三、我的页：余额记录展示优化

### 需求（用户原话归纳）

1. 余额卡内的兑换/消费记录**最多展示 5 条**
2. 提供「更多」入口 → 跳转现金流水明细页
3. 明细页对齐统计页规格：**今天 / 昨天 / 近7天 / 近30天 / 自定义（起止日期）** chips
4. 顶部汇总：**获取多少 / 消耗多少**——消耗是重点，视觉更突出（红色加粗放大）
5. 记录行样式与统计页明细统一（绿收红支）

### 待拍板问题

| # | 问题 | 我的倾向 |
| --- | --- | --- |
| 1 | 超过 5 条要不要做"加载更多"分页 | 不做，日期筛选足够（现金流水增速慢，分页是过度设计） |
| 2 | 明细页要不要类型筛选 chips（全部/兑换/消费） | 要，成本低价值高 |
| 3 | 汇总口径 | 只统计所选时间范围内的获取/消耗，与统计页一致 |
| 4 | 跳转方式 | 独立子页面（带返回），与背包入口同款导航 |

## 四、实施顺序建议

1. **先做第三节**（余额记录优化）：小、独立、立刻改善「我的」页体验
2. **再做第一节**（背包）：宝箱流程改造，按拍板结论开发
3. **第二节**（道具）：等定义清晰后单独立项
