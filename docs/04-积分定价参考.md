### 日收入基准（算账）

**满勤日收入 ≈ 130 分**：

```
早睡 20 + 喝水 20 + boss 5 + 网申 20 + 背八股 20 + 背项目 20 + 力扣 25 = 130
```

- 多轮浮动：背八股/项目每多一轮 +20，力扣每多做一题 +5 → 实际日收入 130 ~ 200+
- 特殊任务不计入基准（偶发）

## 二、惩罚端：未完成扣分（📋 功能待实现）

| 任务 | 罚分 | 触发条件 |
| --- | --- | --- |
| 早睡早起且睡够七小时 | -20 | 当天未完成（2026-09-28 补充） |
| 喝够八杯水 | -20 | 当天未完成（2026-09-28 补充） |
| 背八股 20 分钟 | -20 | 当天一次都没完成 |
| 背项目 20 分钟 | -20 | 当天一次都没完成 |
| 刷力扣 | -25 | 当天没刷满 5 题 |

- 惩罚上限 -105/天；boss/网申无惩罚（自觉项）
- **逾期规则（2026-09-28 用户拍板）**：带截止日期的任务逾期 → 罚分照扣（幂等只扣一次、永不退还）；**任务不删除**，留在列表显示"逾期 N 天"，随时可补完成拿**全额**奖励——有罚分自然功过相抵（净=积分−罚分），无罚分纯拿奖励；行为排序：不做 < 逾期做 < 按期做
- **daily 漏天补罚口径（2026-09-28 用户拍板）**：连续多天没打开 App，回来时**只补罚最近一天**（"昨天"），中间天不追罚——给"消失几天"留缓冲，防止回来先挨一串罚直接劝退
- **实现思路**：任务加"罚分"字段（默认 0）+ 每日结算——打开 App 时惰性结算"昨天"应完成未完成的 daily 任务，写负流水。不依赖定时器。

## 三、支出端：商品定价

### 换算基准（用户确认版）

定价原则：**学习 : 娱乐 ≈ 5 : 1**（用户 2026-09-28 拍板，"20 分钟学习换 4 集短剧，比例可以接受"）。
满勤日收入 130 分，可娱乐消费按短剧计 ≈ 26 集/天。

### 价格锚点说明

旧价格锚表（番剧 60/手游 50-70/电影 200/游戏 130/奶茶 100/外卖 150-200/大额 500-1000）**已按用户要求删除**——不再作为参考，新增商品价格单独和用户讨论。

### 余额系统（✅ 已上线 2026-09-28）

- **10 积分 = 1 元**（用户拍板改 5→10）：月满勤 ≈ 3900 分 = 390 元兑换上限，正好压在"月消费 300-500 顶天"的预算带内——顶格需要几乎全部积分，现金是**最贵的出口**
- 余额 = 现金流水 SUM（兑换 +，消费 -）；消费是**手动记账**：花钱后自己记"买了什么、花了几元"
- 兑换积分需为 10 的倍数（保证整元）
- **购买记录**：商城页"购买记录"按钮 → 弹层 chips 按"全部 / 单个商品"筛选，显示商品（含 ×数量）、扣分、时间

## 五、统计页设计（🔨 2026-09-28 实现中）

用户需求原话要点：看昨天/上周/月统计 + 获取明细 + GitHub 式贡献热力图（当天获得积分越多绿色越深）。

### 页面结构（账本页升级为「统计」页，不新增 Tab）

1. 余额卡（保留）
2. **四格统计卡**：今天 / 昨天 / 本周 / 本月 —— 各显示"获得"积分
3. **昨日明细**：昨天获得的每一笔（当天无数据自动隐藏）
4. **GitHub 式热力图**：最近 26 周（182 天），周一为行首、纵向 7 格、横向按周排列，横向滚动
   - 色阶（绿色系，用户钦定）：0 分灰白 → 1~9 浅绿 → 10~29 中绿 → 30~59 深绿 → 60+ 最深（对满勤 130 分/天）
   - 点击格子显示当天获得积分
5. 流水列表（保留原有）

### 明细筛选与热力图增强（✅ 2026-09-28 二次迭代，用户反馈驱动）

- **明细筛选**：快捷 chips（昨天[默认] / 近7天 / 近30天 / 自定义）；自定义 = 起止日期选择器；显示"范围 + 范围内共获得 N 分"
- **热力图范围**：半年（26 周）/ 一年（53 周）切换，`GET /api/stats?weeks=N`
- **热力图 UI 对齐参考（Token 活动样式）**：月份轴标签、格子紧凑居中消除留白、**鼠标悬停黑色气泡**显示"X月X日 获得 N 分"（移动端点按 toast）
- 后端：`/api/ledger` 加 start_date/end_date 内存过滤 + range_earned 汇总

### 技术口径

- earned = 正数流水之和；spent = 负数流水绝对值
- 周 = ISO 周（周一为一周开始）；月 = 自然月
- 热力图/统计聚合：**内存聚合**（拉全部流水按本地日期分组）——单人数据量小，避免 SQLite 日期函数方言坑
- 后端 API：`GET /api/stats`（一次性返回全部统计）
