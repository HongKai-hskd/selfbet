# 游戏化机制素材库

> 来源：7 个 B 站视频（清单见文末），只留对 SelfBet 机制设计有用的条目，按机制聚类。
> 产品北极星（见 docs/02）：**让自己沉迷学习，学习不枯燥，更乐意主动学习。**
> 产品使命候选：**"你不需要更多的动力，你需要一个不靠动力也能运作的系统。"**[动力]

## 0. 心理依据（为什么能上瘾）

- 多巴胺机制：付出动作 → 立刻得到确定的好处 → 大脑分泌多巴胺 → 驱使人继续
- 大脑吝啬能量：脑力消耗大 + 回报遥远 → 判定"亏本" → 强制犯困走神。学习犯困不是懒，是机制
- 短视频把多巴胺基准线抬高，学习排在快乐排行榜最底层 → 本产品的任务就是把学习顶上排行榜

## 设计铁律

1. **即时**：付出动作 → 秒级到账，不是天级
2. **确定**：完成即发，绝不延迟结算
3. **小**：单任务 5~15 分钟可完成，拒绝大 BOSS
4. **可见**：抽象努力 → 具象堆积
5. **仪式感**：信号要"物理"（视觉+听觉），大脑才认账

## A. 启动机制（对抗"开始难"）

| 机制 | 要点 | 来源 |
| --- | --- | --- |
| 2 分钟规则 | 只承诺专注 120 秒，大脑没反应过来就开始了；开始后惯性延续 | [拖延] |
| 消除启动阻力 | 前一晚把一切准备好，让"做"比"不做"更容易 | [动力] |
| 从小事开始 | 穿上鞋 / 打开文件 / 写一句话，第一步最难 | [动力] |
| 拆小怪 | 任务最小粒度："搞懂两页纸" / "做完五道题"，别立"复习完一整本" | [鱼] |

产品映射：一键开始 / "2 分钟挑战"任务类型 / 任务预设到只剩一个按钮 / 粒度柔性提示（决议见 02）

## B. 赌注与承诺机制（对抗"没动力"）

| 机制 | 要点 | 来源 |
| --- | --- | --- |
| 公开赌约 | 押钱 + 面子："每天不学满 1 小时就给朋友 100 块"——丢钱 + 被嘲笑才是真痛苦 = 真动力 | [拖延] |
| 执行意图 | 公式："如果到了 X 时间，我就做 Y（动作 + 数量）"；"等会学"等于没说 | [拖延] |
| 掷骰子惩罚 | 掷出 6 就做更丢人/更烦的事，让"学习"成为所有选项里最轻松的一条 | [拖延] |
| 睡前留言 | 前一晚写下明天真正要做的 1~2 件事（不是十件），写给未来自己 | [动力] |

产品映射：**押注任务（已定混合制，见 02）** / 任务绑定"时间 + 具体动作" / 每日新任务上限建议 ≤2

## C. 奖励机制（经济系统核心）

| 机制 | 要点 | 来源 |
| --- | --- | --- |
| 固定 + 随机 | 完成即发固定积分；随机宝箱按任务掉率——更刺激更易上瘾 | [每天] + 决议见 02 |
| 小奖 + 大奖分层 | 每日小奖 + 每周大奖；只有真正完成才能领，"打开书本自我安慰"不算 | [每天] |
| 完成动作 = 多巴胺 | 拆小块、打勾、画星星，完成瞬间本身就是一小波奖励 | [游戏] |
| 变率奖励 | 游戏爆装备是概率掉落，随机奖励比固定奖励更上瘾 | 延伸，非视频 |

产品映射：积分到账动效 + 音效（物理多巴胺）/ 开箱动画仪式感 / 完成判定必须严格

## D. 节奏与成长（防劝退、防榨干）

| 机制 | 要点 | 来源 |
| --- | --- | --- |
| 渐进式计划 | 第 1 周 15 分钟/天 → 30 → 45 → 60+，逐周解锁 | [每天] |
| 帕金森定律 | 工作膨胀到占满所有时间 → 内置计时器/倒计时逼出专注 | [作弊][游戏] |
| 番茄钟 25+5 | 大脑喜欢倒计时和有限挑战，把 25 分钟当一局游戏 | [游戏] |
| 每周休息日 | 固定休息日降低焦虑、提高其他天效率；枯燥与有趣内容穿插 | [每天] |

产品映射：新手期时长档位 / 内置倒计时 / 周期性休息日机制

## E. 实体化与状态（外围可选）

| 机制 | 要点 | 来源 |
| --- | --- | --- |
| 实体化进度条 | 玻璃罐装笔芯、草稿纸摞成砖——"哪怕明天不考试，我也知道我在变强" | [鱼] |
| 想象未来自己 | 能清楚看见几年后的自己 → 立刻做出更明智的选择（斯坦福研究） | [每天] |
| 掌控感话术 | "我必须学习" → "我想学习"，大脑喜欢掌控感 | [每天] |
| 多巴胺排毒 | 每天 15 分钟纯无聊，重置被短视频抬高的快乐基准线 | [游戏] |

产品映射：等级/进度条/累计统计/虚拟玻璃罐（形式待定，02 后置项）/ 文案用"选择"框架而非"义务"框架

## F. 明确不录（判定记录，省得回头重看）

学习方法论类解决"**怎么学**"，不解决"**想不想学**"，全部不录入机制库：80/20 法则、先看答案、专注弱点、AI 工具、错题本、睡好觉、上课听讲、画笔记、记忆法、大脑倾倒法等（出自 [作弊][学霸]）。
唯一将来用途：**任务模板库素材**（"整理错题本 20 分钟""费曼复述一节""番茄钟专注 25 分钟"可作为预设任务）。
